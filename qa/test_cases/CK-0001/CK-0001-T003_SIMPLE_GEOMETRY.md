# CK-0001-T003 - Create Simple Geometry

## Metadata
- Test ID: `CK-0001-T003`
- Related work item: `CK-0001`
- Purpose: `Create at least three separate line entities using the simplest currently supported workflow and document the interaction sequence.`

## Preconditions
- CadKit is launched and idle.

## Fixture
- `None`

## Human-Equivalent Actions
1. Activate the simplest line-drawing workflow available to a normal user.
2. Create one line entity.
3. Continue until at least three separate line entities exist.
4. Use `Enter` and `Escape` where relevant to understand completion and cancellation behavior.

## Expected Prompts
- Do not invent exact prompt wording.
- Record the actual prompt sequence shown during line creation.

## Expected Visual Feedback
- Record whether rubber-band preview or other placement feedback appears.
- Record whether created entities become visible immediately.
- Record whether the command appears to stay active after a line is completed.

## Expected Application State
- At least three distinct line entities exist, or the failure mode is documented clearly.

## AutoCAD Reference Behavior
- AutoCAD may be used only as a comparison point for command sequencing and completion feel.

## Pass Criteria
- A normal user can create at least three separate line entities, and the interaction can be described clearly from observed behavior.

## Evidence To Capture
- Screenshot or recording of line creation
- Recorded prompt sequence
- Notes on `Enter` and `Escape` behavior
